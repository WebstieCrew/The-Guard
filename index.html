The Guard

Lightweight & High-Performance Security Engine by WebstieCrew

Real-Time Engine

Monitors system activity continuously to neutralize threats before execution using multi-threaded scanning capabilities.

Custom .c Configuration

Replaces verbose XML formats with a clean, lightweight structured file syntax designed specifically for binary performance.

Automated Vault

Isolates high-risk files instantly into a secure quarantine directory based on configurable threat action policies.

Configuration File Structure (project.c) 
app_info {
    name = "Guard Antivirus";
    version = "1.0.0";
    developer = "WebstieCrew";
    license = "MIT";
}

engine_settings {
    realtime_protection = true;
    scan_threads = 4;
    heuristic_level = "high";
    max_file_size_mb = 100;
}

signatures {
    database_url = "https://signatures.guard.internal/v1/definitions.bin";
    auto_update = true;
    update_interval_hours = 6;
}

action_policies {
    on_threat_detected = "quarantine";
    quarantine_dir = "./vault";
}
